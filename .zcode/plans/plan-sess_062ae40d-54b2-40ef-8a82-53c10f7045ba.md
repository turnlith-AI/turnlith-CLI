# tlc TUI refinement: permission modes, file management, UI polish

All changes stay within the existing architecture (ergochat/readline + hand-rolled ANSI rendering, line-oriented REPL). No new modules — `golang.org/x/sys` (already pinned as indirect, needed for raw-mode key reads) becomes a direct dependency.

## 1. Permission modes: `normal` → `auto` → `yolo`

**`internal/permissions/permissions.go`** — replace the binary `Yolo bool` with a three-state mode:
- `type Mode int` with `ModeAsk` (normal: prompt for every gated tool), `ModeAuto` (auto-approve Write/Edit, still prompt for Bash), `ModeYolo` (approve everything). `Mode.String()` → `"normal"|"auto"|"yolo"`, `ParseMode()` accepts those words (case-insensitive) plus `ask` as alias for normal.
- `Policy{Mode Mode, …}`. `Approve` order: **yolo → allowAll/denyAll session rules → auto+edit → prompt** (so an explicit "never this session" beats auto-approve, but yolo overrides everything as today).

**`internal/tools/tools.go`** — add `Category() string` to the `Tool` interface: `"edit"` (Write, Edit), `"exec"` (Bash), `"read"` (Read, Glob, Grep), `"memory"` (SearchMemory). `permissions.Request` gains `Category`; `internal/agent/loop.go:130` fills it from the tool when building the request.

**Switching UX (no typing required):**
- New `/permissions [mode]` command (table row in `internal/ui/suggest.go:19` → help + `/` menu update automatically). No argument → cycles normal→auto→yolo→normal and prints a styled status line. With argument → sets it (unique prefix accepted).
- `/yolo` stays as a compatibility alias: toggles between normal and yolo (old behavior).
- **TAB completion**: `completeArgument` (`internal/cli/agents.go:93`) gets `case "/permissions": return matching([]string{"normal","auto","yolo"}, prefix)`.
- **Tab at an empty prompt cycles the mode** (Claude Code feel): the readline `Listener` (`internal/ui/repl.go:55`) receives the Tab key even when completion finds nothing (verified in the library source; a bell rings, acceptable). Guard: only when the line is empty and doesn't start with `/`. On cycle: `rl.SetPrompt` + `rl.Refresh` + print the mode line above the prompt.
- **Mode-aware prompt**: normal `❯ ` (accent), auto `⏵❯ ` (yellow), yolo `⏵⏵❯ ` (red). ANSI in prompts is safe — the library's `ColorFilter` strips SGR sequences before width math (verified).
- `--yolo` flag, banner (`cli.go:515`), `/status` (`cli.go:711`), and `printPrompter`'s message all switch to the mode vocabulary. `helpText` const's REPL command list updated.

## 2. File management (new — nothing user-facing exists today)

### a) `@path` mentions with TAB completion
- **Completion**: `CompletionWords` (`internal/ui/suggest.go:78`) currently bails on non-`/` lines — extend it: if the token under the cursor starts with `@`, delegate to the same `extra` hook. New `internal/cli/pathcomplete.go`: walks the cwd (skipping `.git`, `node_modules`, … — export the skip list from `internal/tools/util.go` as `tools.IsSkipDir`), matches the typed text against the relative path **from the start or from any directory boundary** (so `@cli.go` finds `internal/cli/cli.go`), directories complete with a trailing `/`, dirs-first ordering, caps (≈50 candidates, ≈10k walked entries).
- **Expansion**: new `internal/cli/mentions.go`. On submit (interactive and `-p` modes), find `@token` via regex, resolve against cwd, files only; skip binaries (NUL byte in first 8 KB); per-file cap (2500 lines / 96 KB) with a truncation note. The wire prompt becomes the user text plus `<file path="…">…</file>` blocks; the local transcript keeps what the user typed; each attached file is `tracker.MarkRead` so the model can Edit it immediately; a dim notice prints `· attached internal/ui/repl.go (6.2 KB)`. Unresolvable mentions (emails etc.) stay literal.

### b) `/files` interactive browser
- New `internal/ui/browser.go` (unix build tag): takes over the terminal in raw mode and renders a listing with a cursor —
  - Section 1: files touched this session (badges R/W/E, from the extended Tracker below); Section 2: current directory (dirs first, sizes), breadcrumb header, footer key legend.
  - Keys: `↑↓`/`jk` move · `→`/`Enter` enter dir or pick a file · `←`/`u` parent · `/` filter as you type · `r` refresh · `q`/`Esc` close. Height-aware (TIOCGWINSZ via x/sys), capped rows, in-place redraw.
  - Picking a file closes the browser and **pre-fills the next prompt** with `@rel/path ` via `Instance.ReadLineWithDefault` (exists in the library, readline.go:225) behind a small `REPL.Prefill` field.
- Windows fallback (`browser_other.go`, no build tag conflict): renders the same listing statically with a hint, no interaction. Keeps the release matrix (includes windows) green.
- Listing model, filtering, and key→action mapping are pure functions so they're unit-testable without a tty.

### c) Tracker extension (`internal/tools/tools.go`)
- Record per-path activity: read / written / edited + last-touch time. `WriteTool`/`EditTool` call `MarkWritten`/`MarkEdited` on success. `Files()` snapshot sorted by recency — powers the browser's session section; `/status` gains a `files:` count line.

## 3. UI polish

- **Single-key permission prompts**: `REPL.Prompt` (`internal/ui/repl.go:101`) reads one raw key instead of a typed line — `y`/Enter allow · `a` always · `n` deny · `x` never · Ctrl-C abort; the pressed key is echoed under the block. Raw read via `golang.org/x/sys/unix` termios (save/restore), shared with the browser; Windows keeps the current typed-line flow behind a build tag. `PermissionBlock` (`internal/ui/render.go:175`) gains a `⏺ Tool(summary)` header line above the preview and the options line becomes `[y] allow · [a] always · [n] deny · [x] never`.
- **`/` menu and `/help`**: replace the single long command-name line (`suggest.go:55`) with the same aligned two-column table `/help` shows (name+args | description), colorized via the theme; still printed once when `/` opens a line.
- **Ctrl-C twice to quit**: README already claims it; today Ctrl-C at an empty prompt is swallowed forever (`cli.go:483`). First press prints `press Ctrl-C again to quit`, second exits.
- **Banner**: keep two lines, add the permission mode to the hint line.
- Prompt glyph `>` → `❯` (theme.go glyph constant).
